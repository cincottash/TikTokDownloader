# TikTokDownloader
Downloads all your liked videos

## Usage
* Extract yt-dlp.exe from yt-dlp.zip and add it to PATH
* Navigate to your liked videos on Tiktok.com and save the HTML as ExampleLikedVideos.htm in this directory
* Run download.sh

## Example
I have included the HTML of my liked videos as ExampleLikedVideos.htm.  You can verify the program works with this test file.
